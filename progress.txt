## Codebase Patterns
- Project uses Next.js 16 (App Router) with TypeScript strict mode
- Prisma 7 requires driver adapters (using @prisma/adapter-pg) - no direct DB URL in PrismaClient constructor
- Prisma client is generated to `src/generated/prisma/` - import from `@/generated/prisma/client`
- Tailwind v4 with `@theme inline` for custom tokens (not tailwind.config.js)
- ESLint 9 flat config with eslint-config-next + eslint-config-prettier
- Global prisma singleton in `src/lib/prisma.ts` using adapter pattern
